# DIGITALTRACK_BRAND

Private brand repository for DigitalTrack.

This repo is the reusable source of truth for AI agents, design workflows, and branded deliverables. It is intentionally curated. Raw working files stay outside this repo unless they are explicitly approved for inclusion.

## Structure

```text
AGENTS.md
CLAUDE.md
docs/
  brand/
    DIGITALTRACK_BRAND_AGENT.md
assets/
  logos/
references/
  brand-guideline-pages/
licenses/
  fonts/
    montserrat/
```

## What Lives Here

- agent-ready brand guidance
- approved or working logo assets
- selected guideline pages that contain enforceable brand rules
- font license/reference files

## What Stays Out By Default

- Canva edit links
- personal contact details unless needed
- oversized PSD, AI, and ZIP working files
- placeholder or template-only brand pages

## Primary Entry Point

For AI-assisted work, start with:

- `docs/brand/DIGITALTRACK_BRAND_AGENT.md`
