# Logo Assets

This folder contains a small curated set of DigitalTrack logo exports.

## Included

- `digitaltrack-logo-black.png`
- `digitaltrack-logo-blue.png`
- `digitaltrack-logo-grey.png`
- `digitaltrack-logo-white.png`
- `digitaltrack-circle-logo.svg`

## Notes

- The main working logo exports currently available in this repo are raster PNGs plus the circle-logo SVG.
- The full wordmark vector source appears to exist in the local source folder as an `.ai` file, but it is intentionally not tracked here in the first pass.
- If a clean SVG or PDF export of the full wordmark is created later, it should be preferred over PNG for implementation work.
