# Agent Instructions

Before writing copy, creating designs, or changing brand-facing UI, read:

- `docs/brand/DIGITALTRACK_BRAND_AGENT.md`

Hard rules:

- Do not invent mission, vision, or values from template pages.
- Use confirmed DigitalTrack logo and color rules from the brand doc.
- Prefer Montserrat unless a newer official source overrides it.
- Keep tone practical, local-business focused, and results-oriented.
- Treat files in `references/brand-guideline-pages/` as visual evidence, not as license to infer missing strategy.

Repo handling rules:

- Keep this repo curated.
- Do not add raw Canva edit links to tracked files.
- Do not add PSD, AI, or ZIP files unless explicitly approved.
